# Deep Learning Practicals

Deep Learning laboratory notebooks implemented with Python and TensorFlow/Keras.

## Experiments

| No. | Notebook | Topic |
| --- | --- | --- |
| 1 | `Experiment-1/Experiment_1.ipynb` | Single-layer perceptron |
| 2 | `Experiment-2/Experiment_2.ipynb` | Multi-layer perceptron on the Breast Cancer dataset |
| 3 | `Experiment-3/Experiment_3.ipynb` | ANN optimizers: SGD, Adam, and RMSprop |
| 4 | `Experiment-4/Experiment_4.ipynb` | ANN regularization with Dropout, L2, and Batch Normalization |
| 5 | `Experiment-5/Experiment_5.ipynb` | CNN from scratch on CIFAR-10 |
| 6 | `Experiment-6/Experiment_6.ipynb` | VGG16 fine-tuning on a custom image dataset |
| 7 | `Experiment-7/Experiment_7.ipynb` | IMDB sentiment analysis: LSTM vs. Simple RNN |

## Requirements

Use Jupyter Notebook with Python 3 and install the packages required by the individual notebooks, including TensorFlow, NumPy, Matplotlib, and scikit-learn.

## Experiment 6 dataset

The custom image dataset is intentionally not stored in this repository. See `Experiment-6/README.md` for the expected folder layout and setup instructions.
